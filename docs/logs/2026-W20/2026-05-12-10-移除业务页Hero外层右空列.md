# 移除业务页 Hero 外层右空列

## 问题

虽然前一轮已经把业务页 Hero 的统计区与说明卡做成并排填充，但截图显示首页外页面仍然存在明显右侧空白。

根因是：

- `page-hero` 基础样式默认仍是双栏大 Hero 容器
- `variant="minimal"` 只是覆盖了 `grid-template-columns`
- 外层容器仍保留了展示型 Hero 的布局轨道，导致视觉上像是右边留了一整列空区

## 修改

本次继续收口 `frontend/src/styles/main.css`：

- 将 `page-hero.variant-minimal` 从双栏 grid 容器改为单块容器
- 强制 `page-hero-copy`、`page-hero-support-grid`、`page-hero-inline-visual` 宽度为 `100%`
- 将 `page-hero-support-grid.has-stats.has-visual` 改为真正对半分的两列
- 保证右侧说明卡在同一内容块内展开，而不是挂在外层第二列轨道上

## 结果

修复后：

- 业务页 `minimal` Hero 不再继承外层展示型右侧列
- 左侧内容与右侧说明卡会在同一个内容区内铺满
- 原先截图中的大面积右侧空白被移除

## 验证

已执行：

```powershell
cd frontend
npm run build
```

结果：构建通过。
