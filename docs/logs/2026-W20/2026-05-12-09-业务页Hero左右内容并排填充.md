# 业务页 Hero 左右内容并排填充

## 需求

用户要求不要再额外设计右侧摘要列，而是直接将左侧已有内容逻辑填充到右侧空白区域中，优先快速消除业务页首屏右侧的大面积留白。

## 修改

本次修改集中在：

- `frontend/src/components/PageHero.vue`
- `frontend/src/styles/main.css`

处理方式：

- 对 `variant="minimal"` 的业务 Hero，不再保留独立右侧视觉列
- 将原本左侧已经存在的统计信息区与插槽内容整合进同一个 `page-hero-support-grid`
- 当页面同时存在统计卡和右侧插槽时，自动并排显示
- 当页面只有统计卡或只有插槽时，仍保持单列兼容
- 保留窄屏自动回落为单列的响应式行为

## 效果

调整后，业务页首屏下半区会改为：

- 左侧放统计卡
- 右侧放原有说明卡或摘要卡
- 两部分共同占满首屏内容区

这样修复后，不需要为每个页面单独造新的右栏内容，也不会再出现整块空白区域。

## 验证

已执行：

```powershell
cd frontend
npm run build
```

结果：构建通过。
