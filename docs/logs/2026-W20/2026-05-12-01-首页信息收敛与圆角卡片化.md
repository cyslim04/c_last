# 2026-05-12 首页信息收敛与圆角卡片化

## 本次目标

- 继续优化首页，减少说明性废话
- 为首页主要盒体增加更明显的圆角
- 保留核心入口、流程结构和少量运行信号

## 主要修改

### 1. 首页文案收敛

- 压缩 Hero 主标题，改为更短的入口表达
- 删除首屏大段解释性说明，仅保留一句副标题和一句概述
- 角色入口卡片移除要点列表，只保留角色定位与操作入口
- 四步协作文案缩成短标题与短说明
- 运行信号区删除多余描述，只保留核心状态信息
- 底部 CTA 删除解释段落，只保留入口收口

### 2. 首页卡片圆角化

- 将首页从整块分隔式板面调整为多张独立卡片
- 首页大板块统一改为更明显的圆角盒体
- Hero 右侧四象限结构卡增加圆角和裁切
- 角色卡、流程卡、摘要卡、待办卡、侧边状态卡统一圆角化
- 移动端同步保留圆角和边框，不再回退成旧式线性分隔布局

## 影响文件

- `frontend/src/views/HomeView.vue`
- `frontend/src/styles/main.css`

- 执行 `frontend` 下的 `npm run build`
