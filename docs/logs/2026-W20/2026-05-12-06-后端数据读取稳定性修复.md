# 2026-05-12 后端数据读取稳定性修复

## 本次目标

- 修复后端数据读取经常异常的问题
- 提高主数据接口在大响应和空值场景下的稳定性
- 避免前端把坏数据静默吞掉

## 主要修改

### 1. 后端响应稳定性

- 将后端 JSON 响应缓冲区上限从 `262144` 提高到 `1048576`
- 新增统一的安全拼接函数，避免大响应直接累加时越界写入
- 优先修复首页和高频业务依赖的主数据接口：
  - `dashboard`
  - `projects`
  - `worklogs`
  - `deliverables`
  - `audit`

### 2. SQLite 文本读取保护

- 新增 `sqlite_text_or_empty` 与 `copy_sqlite_text`
- 避免字段为空时直接把 `sqlite3_column_text` 当成普通字符串读取
- 修复用户资料与阶段快照等高频路径的空值读取风险

### 3. 前端错误可见性

- 前端 API 层不再把非法 JSON 静默当成空对象
- 后端返回坏数据时，页面会直接报出明确错误，方便继续定位

## 影响文件

- `backend/src/server.c`
- `frontend/src/api/http.js`

## 验证计划

- 执行 `backend/build.ps1`
- 执行 `frontend` 下的 `npm run build`
- 重新启动后端并验证 `dashboard / projects / worklogs / deliverables / process-flow / audit`
