# 首页外业务页 Hero 收敛与 UI 修复

## 问题背景

首页完成收敛后，首页之外的业务页仍沿用了偏展示型的大 Hero 规格，导致多个页面出现相同问题：

- 标题字号过大，业务页首屏被挤压
- 右侧说明卡与统计卡比例失衡，形成大面积留白
- 项目创建、工时、审计等页面文案过长，进一步放大排版问题
- 共用 Hero 默认模式过于接近首页展示区，不适合登录后的业务操作页

## 本次修改

### 1. 收紧共用 Hero 默认规格

修改 `frontend/src/components/PageHero.vue` 与 `frontend/src/styles/main.css`：

- 将 `PageHero` 默认 `size` 从 `default` 改为 `compact`
- 收紧 Hero 容器宽度比例、间距、内边距和标题最大宽度
- 降低业务页标题字号与行高，避免多行业务标题撑满首屏
- 收紧描述、统计卡、右侧说明卡的尺寸与行高
- 降低 Hero 背景强调层强度，避免业务页继续保留过强展示感

### 2. 批量收短业务页 Hero 文案

为以下页面统一改成更短、更偏操作语义的标题和说明：

- `ProjectsView.vue`
- `WorklogsView.vue`
- `DeliverablesView.vue`
- `ConfirmationsView.vue`
- `AuditView.vue`
- `MembersView.vue`
- `ProfileView.vue`
- `ProjectManagementView.vue`
- `ProcessFlowView.vue`

处理方式：

- 标题改为一句核心动作
- 描述缩短为一行业务解释
- 右侧说明卡只保留当前对象与下一步动作，不再堆叠长说明
- 将原本仍偏展示型的页面统一切到 `variant="minimal"`

## 结果

修复后，首页外业务页的首屏结构重新回到“轻 Hero + 业务面板”的比例：

- 标题不再堆叠挤满首屏
- 右侧卡片不再把布局拉空
- 统计卡高度与文字密度更接近业务台，而不是营销首页
- 共用模板层收口后，后续新增业务页也会默认使用更稳的紧凑规格

