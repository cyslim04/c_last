# 系统说明

## 定位

Trust Work 用于管理独立协作项目中的工时、交付物、客户确认、阶段审计和链上证据。系统由管理员、开发者和客户三类角色组成。

## 技术组成

- 前端：Vue 3、Vite、Pinia、Vue Router、Ethers.js
- 后端：C11、Winsock2、SQLite3、自研 SHA-256 工具
- 合约：Solidity、Hardhat

## 角色职责

- 管理员：管理成员、创建项目、查看项目状态、执行阶段审计和最终审计。
- 开发者：绑定钱包、登记工时、登记交付物、提交链上存证。
- 客户：查看阶段材料、确认或驳回交付物。

## 业务流程

项目按阶段推进。开发者在当前阶段提交工时和交付物，客户完成阶段确认后，管理员执行阶段审计；所有阶段完成后，管理员执行最终审计。工时摘要和文件哈希用于后续确认与审计，链上交易哈希保存在证据记录中。

## 权限与数据

登录后根据角色限制路由和接口访问范围。项目成员只能访问自己参与的项目，管理员可管理全局项目和成员。系统不内置账号、项目或示例数据。
