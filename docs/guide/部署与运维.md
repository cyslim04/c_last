# 部署与运维

## 环境要求

- Windows
- GCC
- SQLite3 开发库
- Node.js 和 npm
- 如需合约开发，安装 Hardhat 依赖

## 首次初始化

在空数据库中执行：

```powershell
cd backend
.\init-admin.ps1
```

脚本会安全读取管理员账号和密码。数据库已有用户时，初始化会拒绝执行。

## 启动服务

```powershell
cd backend
.\run.ps1

cd ..\frontend
npm install
npm run dev
```

后端默认监听 `http://localhost:8080`，前端默认运行在 `http://localhost:5173`。

## 构建与合约

```powershell
cd backend
.\build.ps1

cd ..\contracts
npm install
npm run test
npm run compile
```

不要提交数据库、可执行文件、前端 `dist/` 或真实密钥。合约部署配置使用 `contracts/.env.example` 作为模板。
