# 接口与数据

## 认证

- `POST /api/auth/login`
- `GET /api/auth/me`
- `PUT /api/auth/profile`
- `PUT /api/auth/password`
- `POST /api/auth/avatar`
- `POST /api/auth/logout`
- `POST /api/auth/wallet`

系统不提供公开快捷账号接口，也不向客户端返回明文密码。

## 成员与项目

- `GET /api/users`
- `POST /api/users`
- `PUT /api/users`
- `POST /api/users/password/reset`
- `POST /api/users/status`
- `DELETE /api/users?id=<id>`
- `GET /api/projects`
- `POST /api/projects`

## 工时、交付与审计

- `GET/POST /api/worklogs`
- `GET/POST /api/deliverables`
- `POST /api/evidence`
- `GET /api/dashboard`
- `GET /api/audit`
- `POST /api/audit/stage`
- `POST /api/audit/final`
- `GET /api/process-flow`

## 主要数据表

- `users`：账号、角色、状态和资料
- `wallet_bindings`：钱包绑定历史
- `projects`、`project_members`：项目及成员关系
- `worklogs`：阶段工时和摘要
- `deliverables`：交付版本、文件哈希和确认意见
- `approval_records`：客户确认记录
- `project_audits`：阶段审计与最终审计
- `evidence_records`：链上交易回写
- `audit_logs`：后台操作留痕

状态枚举和阶段推进规则以数据库字段及后端校验为准。
